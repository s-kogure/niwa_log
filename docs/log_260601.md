### 決定事項

**1. 地域サジェスト API の選定**
- サジェスト（名前→候補一覧）：HeartRails Geo API（日本特化・無料・APIキー不要）
- 天気取得：OpenWeatherMap（既存方針通り）
- `regions.external_id` には HeartRails が返す郵便番号（`postal`）を使用
- フロー：ユーザー入力 → HeartRails でサジェスト → 選択時に `{ name, lat, lng, postal }` を取得 → `postal` を external_id として regions に upsert → lat/lng を OWM に投げて天気取得

**2. 植物マスタ 2階層制約の担保場所**
- アプリ側（サービス層）で担保する方針に決定
- DBトリガーは使わない
- INSERT 前に `parent_id` の `parent_id` が NULL かチェックするシンプルな実装で対応

**3. user_roles の複数ロール対応**
- 将来的に複数ロール付与を許容する（特にモデレーター権限のサブ付与を想定）
- 複合ユニーク制約は `(user_id, garden_id)` ではなく `(user_id, garden_id, role)` にする
- moderator は引き続き `users.is_moderator`（グローバルフラグ）で管理
